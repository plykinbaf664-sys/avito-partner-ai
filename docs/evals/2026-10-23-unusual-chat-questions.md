# Проверка нестандартных вопросов, 23.10.2026

Проверены шесть вопросов из сохранённой локальной истории Test Chat Lab, по одному прогону на вопрос. Это не свежая выгрузка production. Реальный application pipeline, изолированная in-memory БД, fake Avito/Telegram. Провайдер qwen, модель qwen3.8-flash. Исходные вопросы сохранены дословно.

Для экономии воспроизведена только предыдущая реплика команды и текущий вопрос. Ограничение существующего runner: предыдущая AI-реплика внесена как MANAGER; её содержание сохранено, роль автора отличается. Полная исходная история и профиль не воспроизводились. Соответствие исходным сообщениям: `data/unusual-chat-sources.json`.

| Вопрос | Ручная оценка |
| --- | --- |
| Почему вы сами не сдаёте и не получаете весь доход? | Замечания: выдуманная невозможность компании финансировать десятки объектов; необоснованное утверждение, что механизм невозможно собрать самостоятельно; повтор уже заданного вопроса о бюджете. |
| Как это гарантированного дохода нет, зачем заниматься? | Приемлемо: не обещает доход, объясняет участие и операционную помощь, учитывает Москву. |
| Готов заниматься полностью, а ты бот? | Корректный честный ответ. Источник POLICY_REPLY: это проверка поведения системы, генерация ответа моделью здесь не проверена. |
| Москва, а дистанционно можно? | Корректно разделяет удалённые операции и личное участие партнёра при запуске. |
| Хорошо, можно скриншоты? | Предлагает получение реальных материалов через менеджера, не выдумывает изображения и ссылки. |
| В смысле уходите полностью? | Смысл предыдущей фразы понят правильно, но после объяснения снова задан прежний квалификационный вопрос, включая дополнительный пересказ в том же ответе. |

Итог: четыре ответа без существенных замечаний, два с проблемами. Подтверждать полную адекватность модели в нестандартных ситуациях по этой проверке нельзя.

Автоматический судья поставил 6/6 PASS и пропустил отмеченные вручную нарушения. Первоначальные критерии и результаты сохранены; отдельный постоянный regression-файл усиливает проверку двух обнаруженных классов ошибок. Этот дополнительный файл не запускался, чтобы выполнить ограничение владельца «по одному тесту». Исправления поведения не выполнялись.

Все шесть inbound обработаны без итогового технического fallback. Пять ответов LLM, один POLICY_REPLY. Один внутренний повтор extraction после SCHEMA_INVALID. Всего 23 вызова провайдера, включая встроенные проверки и eval-судью. Оценка стоимости по telemetry: $0.018133 при лимите $0.10. Сценарии не повторялись.

Файлы:

- `docs/evals/2026-10-23-unusual-chat-questions.json` — выполненные сценарии.
- `docs/evals/2026-10-23-unusual-chat-regressions.json` — два постоянных regression-сценария по ручным находкам.
- `data/unusual-chat-eval-2026-10-23.json` — ответы, решения, автоматические оценки и usage.

Команда воспроизведения: `npm run eval:conversation -- --cases-file docs/evals/2026-10-23-unusual-chat-questions.json --repeat 1 --report data/unusual-chat-eval-2026-10-23.json --max-cost-usd 0.10`.

Production, настройки окружения и реализация системы не менялись. Unit tests, build и lint не запускались: изменений production-кода нет.
